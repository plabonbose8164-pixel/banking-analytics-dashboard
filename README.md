# Banking Sector Analytics Dashboard

An end-to-end banking analytics project using Python, Excel and Tableau to analyze banking performance, financial trends and key business indicators.

## Project Overview

This project analyzes banking-sector data to identify trends in financial performance, customer-related metrics and market indicators.

The workflow combines:

- Python for data cleaning, preprocessing and analysis
- Excel datasets for structured banking and stock-market data
- Tableau for interactive data visualization and dashboard development

## Analysis Performed

### Data Preparation

The datasets were cleaned, processed and prepared for analysis using Python.

Key steps include:

- Data cleaning and preprocessing
- Dataset merging
- Handling and structuring banking data
- Preparing data for visualization and analysis

### Banking Analysis

The project explores key banking-sector metrics and performance indicators to identify trends and patterns across institutions and time periods.

### Stock Market Analysis

Bank stock-market data was analyzed to examine market performance and trends across selected Indian banking institutions.

## Tableau Dashboard

An interactive Tableau dashboard was developed to present the analysis through visualizations and business-oriented insights.

The dashboard enables exploration of banking-sector performance and related financial trends.
